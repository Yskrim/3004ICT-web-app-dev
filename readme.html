Software Development Environment

Welcome to your Software Development Environment. This server contains tools for developing web application with PHP 8.4, and an Apache 2.4 web server. The software installed in this environment include Apache with PHP, code-server, PHP composer (to install Laravel), and other PHP, NodeJS, MongoDB, SQLite, mysql-client, and many other packages.

If you require some other software package, you can make a request to your academic lecturer, who will forward it to the Unversities S3 Linux team.

  • For more information about this server and the software development environments you are using, see the service welcome page at

    https://elf.ict.griffith.edu.au/

     

  • A Web based User-interface based on code-server has been installed, and should be running on

    https://{s-number}.elf.ict.griffith.edu.au/

    This interface will require you to login via the users SSO authentication system.  

  • Your apache web server is online at this URL...

    https://{s-number}-80.elf.ict.griffith.edu.au/

    refers to the "~/html/" directory of your environment's working home. Hence the html file you are reading now resides in the file "~/html/readme.html".

    You are free to create other files and directories under "~/html/" to house your web projects and exercises (in HTML, PHP or Laravel). However anything in this directory is public, so any security related information (configs, passwords, etc) should not be saved here.

    As this directory is public (to the university network), you are expected to be responsible, and not post matter that is inappropriate, offensive, or NSFW. It is your responsibility to become familiar with the IT Code of Practice.

    Also please do not publish any Personal Identity Information (PII) such as your name, address, phone numbers, etc., in these web pages. This is a concern for the security of you and the university as a whole.

     

  • A "Node.js" application can be created outside the Apache "html" sub-directory, and can use either ports 3000 or 3001 (HTTP protocol)... For example if using 3000, then when run it will be accessible on the URL...

    https://{s-number}-3000.elf.ict.griffith.edu.au/

     

  • To install the Laravel Software, run

    composer global require laravel/installer

    To create a laravel server project, please read Creating a secure laravel project. This is important information as it describes how to create a sub-directory containing a secure laravel project.

    Do not rely on other similar information that can be found on the web, as these are, more often than not, insecure. See the above documentation for more detail.
