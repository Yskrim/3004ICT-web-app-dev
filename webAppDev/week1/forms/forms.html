GET sends the form data in URL parameters. Data in this case is accessible via URLsearchParams, hovewer it can't be accessed directly. In order to access the entries, the script has to iterate through the object and add the new elements to the page. This is much easier with React and not as much but still easy with Angular

Get forms are to be used in search requests, when we don't know what data to expect like google search.



POST method on the other hand wraps the passed values into html request to the server. Normally every page should have some sort of server connected to it to perform calculations. But there is a practice of making some apps a monorepo, which enables a frontend app to make, send requests and process html responses without exposing logic or API keys to the frontend. The data won't be accessible via parameters, though still interceptable when someone is sniffing on an unsecured network.

Post requests are used when we need to send the data to the server to process it. Like login, file uploads, changing something.
